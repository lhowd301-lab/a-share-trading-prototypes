# A 股日内交易研究原型

右侧交易、分钟级回测、信号监控与布林带信号的历史原型。

## 模块

| 目录 | 内容 |
| --- | --- |
| `right_side/` | 指标、仓位、风险规则和信号研究。 |
| `minute_backtest/` | 分钟行情、回测引擎与本地展示。 |
| `monitor/` | 指标、信号、状态存储与本地监控。 |
| `et_signal/` | 从 ET 历史策略提取的行情与布林带信号，不含券商客户端连接和下单。 |

```bash
python -m pip install -r requirements.txt
cd right_side
python main.py
```

Python 3.10+。各模块为独立历史实现，需在对应目录运行。监控原型可能启动本地服务或抓取行情，不会因语法检查而运行。`et_signal/strategy.py` 可用于研究信号，原始实盘执行程序和交易日志未上传。

## 数据与局限

账户规模、股数、成本已替换为演示值；真实持仓、成交、缓存、补丁和实习报告不公开。信号与撮合机制尚未经过完整交易规则审计；A 股 T+1、涨跌停、流动性和交易成本必须在具体实验中处理。此仓库的结果不能被视为验证过的盈利策略。
